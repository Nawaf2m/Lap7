# Education Management System

A simple Spring Boot project for managing courses and assignments.

## Course
The Course section allows users to:
- CRUD
- Get courses by category
- Get courses by credit

### Course Attributes
- id
- name
- category
- credit

## Assignment
The Assignment section allows users to:
- CRUD
- Get upcoming assignments
- Get assignments by title

### Assignment Attributes
- id
- title
- description
- dueDate

## Technologies
- Java
- Spring Boot
- REST API
- Validation
